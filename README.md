# TALLBOY

**Your track, played back on a handheld.**

TALLBOY pitch-tracks whatever you feed it and replays the performance on four
modelled console sound-chip channels, then arpeggiates and decimates it. No
knobs — you drive it with a D-pad and a dot-matrix screen.

By [Carbonated Audio](https://carbonatedaudio.com) · **$20 one-time**, no
subscription, no iLok, three machines per licence.
